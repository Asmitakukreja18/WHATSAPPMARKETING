# Next ReachDMS — Enterprise CPaaS & WhatsApp Marketing Platform

Next ReachDMS is a high-throughput conversational marketing and CPaaS (Communication Platform as a Service) platform designed for scaling businesses across India, UAE, and global markets.

## 🚀 Key Features

### 1. 🌐 Public Platform Website
- **WhatsApp Broadcasts**: High-volume promotional campaigns with SmartQueue™ anti-ban throttling.
- **Official Meta Business API**: Fast-track Green Tick badge verification, 24/7 AI conversational bots, and multi-agent shared inboxes.
- **ReachSMS Gateway**: 2-Second fast OTP delivery, TRAI DLT compliance management.
- **Google RCS Messaging**: Next-gen rich messaging with brand headers, carousels, and 1-tap action buttons.
- **Voice OBD Calls**: Automated voice broadcasts, IVR surveys, and DTMF keypress capture.
- **Interactive Pricing Calculator**: Dynamic volume estimator for 1 Lakh to 50 Lakh+ messages.
- **Free Demo Onboarding**: Instant sign-up with 100 free test credits.
- **Customer Success Case Studies**: Proven ROI metrics across Retail, D2C E-Commerce, Real Estate, and Education.

### 2. 📊 Logged-In SaaS App Workspace
- **Analytics Dashboard**: Real-time hourly traffic chart, KPI statistics (1.15M sent, 99.4% SLA, 3.85M credits remaining).
- **Contact Management**: Group segmentation with active WhatsApp number verification and auto-clean.
- **Message Composer**: Real-time smartphone preview simulator with dynamic variable insertion (`{Name}`, `{DiscountCode}`).
- **1-Click Send Campaign**: Live progress bar with credit deduction and real-time status animation.
- **Detailed Number Logs**: Granular per-number delivery audit log (*Delivered*, *Blue-Tick Read*, *Failed with auto-refund*).
- **Live Shared Inbox**: Interactive 2-way customer chat simulation with quick replies.
- **Integrations Hub**: Webhook triggers for Shopify, HubSpot, Zapier, Razorpay, and OpenAI GPT-4o.
- **Number Filter Tool**: Built-in phone number validator to eliminate non-WhatsApp contacts.

## 🎨 Design & Architecture
- **Theme**: Default Light Theme with high-contrast slate typography and cyan/emerald accents.
- **Responsiveness**: 100% Mobile, Tablet, and Desktop responsive layout.
- **Dual-Mode**: Single-click top toggle between Public Website and SaaS App Dashboard.

## 💻 Quick Start

To run locally:
```bash
# Using Node / npx
npx serve -l 5000 .

# Or using Python
python -m http.server 5000
```
Open [http://localhost:5000](http://localhost:5000) in your web browser.
